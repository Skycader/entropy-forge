# Случайность: источники, хеши, seed, генераторы

[← welcome](welcome.md)

Всё ниже сверено с кодом [`js/hash.js`](../js/hash.js), [`js/prng.js`](../js/prng.js),
[`js/entropy.js`](../js/entropy.js), [`js/app.js`](../js/app.js).

## Конвейер

```
отпечаток = H(источник)
mix       = H(отпечаток + ":" + соль)        // для djb2 — растяжка счётчиком, см. ниже
seed      = первые N байт mix                // N = размер состояния генератора
числа     = G(seed)                          // новый генератор на каждый клик
```

Результат зависит **только** от: H, G, поля отпечатка, поля соли, типа и параметров
(`a`/`b`, длина, алфавит). Одинаковые входы → одинаковый результат.

## Источники

| Источник | Что хешируется |
|---|---|
| Рисунок | `packPool(points)`: на каждую точку 16 байт little-endian — `float32 x`, `float32 y`, `float64 t` (`performance.now()`). `x, y` — в координатах холста на момент начала пула. Нужно ≥ 3 точек, иначе источник «пуст» |
| Текст | md5 / sha256 — UTF-8 байты строки как есть (совпадает с любым внешним калькулятором); djb2 — коды символов JS (`charCodeAt`, UTF-16), как в эталонном коде в подсказке |

## Хеш-функции

| H | Выход | Отпечаток в поле | Потолок энтропии |
|---|---|---|---|
| `djb2` | 4 байта (uint32, big-endian) | десятичное число, как `console.log(djb2(...))` | 32 бит |
| `md5` | 16 байт | 32 hex | 128 бит |
| `sha256` | 32 байта | 64 hex | 256 бит |

Все три — на чистом JS, синхронно (WebCrypto не используется). MD5 и SHA-256 сверялись
с `crypto` из Node в ходе разработки, вручную — автотестов нет.

DJB2: `hash = 5381; hash = hash*33 + c` (через `(hash << 5) + hash`), `|= 0`, на выходе `>>> 0`.

### Растяжка для djb2

`mix` должен дать до 16 байт, а djb2 даёт 4. Поэтому:
`mix = djb2(src + ":0") ‖ djb2(src + ":1") ‖ djb2(src + ":2") ‖ djb2(src + ":3")`,
где `src = отпечаток + ":" + соль`, каждый блок — uint32 big-endian. Энтропии по-прежнему
не больше 32 бит. Блоки получаются похожими (входы отличаются последним символом) —
это наглядная слабость djb2, оставлена намеренно.

## Соль

- Галочка включена: `Date.now()`, округлённый вниз до шага. Шаг задаёт ползунок в поле:
  1000 позиций, логарифмически 1 мс…60 000 мс (`stepMs()` в `app.js`). Шаг < 16 мс
  обновляется через `requestAnimationFrame`, иначе — `setTimeout` до следующей границы.
- Ввод вручную снимает галочку и останавливает тикер. Касание ползунка включает галочку снова.
- Генерация берёт значение, которое видно в поле в момент клика.

## Генераторы

| G | Состояние = seed | Как читается seed | Выход | Потолок |
|---|---|---|---|---|
| `lcg` | 8 байт | одно uint64 big-endian (= hex в таблице) | `X = (a·X + c) mod 2⁶⁴`, `a = 6364136223846793005`, `c = 1442695040888963407` (Кнут, MMIX); число = старшие 32 бита | 64 бит |
| `sfc32` | 16 байт | четыре uint32 little-endian; 20 холостых шагов | SFC32 (Small Fast Counter, PractRand) | 128 бит |

Каждый клик создаёт **новый** генератор из текущих полей — поток не продолжается между кликами.

## Примитивы (`prng.js`)

| Функция | Как |
|---|---|
| `randInt(rng, a, b)` | границы обрезаются до ±`MAX_SAFE_INTEGER`; диапазон ≤ 2³² — rejection sampling по uint32; шире — точная арифметика `BigInt` |
| `randDouble(rng)` | 53 случайных бита → `[0, 1)`, никогда не округляется до 1 |
| `randomString(rng, len, charset)` | байт `floor(rng()*256)`, отбрасываются байты ≥ `floor(256/n)·n` — равномерно для любого алфавита ≤ 256 символов |

`CHARSETS`: `upper` (26), `lower` (26), `digits` (10), `special` (32 знака ASCII:
`` !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~ ``). Длина строки 1–512.

## Оценка энтропии

**Рисунок** (`estimateBits`): по соседним точкам внутри штриха — гистограммы направления
(16 корзин, шаги длиннее 0,4 px) и дробной части интервала времени (16 корзин).
`биты = (n_dir · H_dir + n_time · H_time · 0.5) / 5` — делитель 5 учитывает корреляцию
соседних точек.

**Текст** (`estimateTextBits`): `log2(алфавит) × (уникальные символы + ¼ на повтор) × язык`,
где алфавит — сумма использованных классов (a-z 26, A-Z 26, 0-9 10, а-яё 33, А-ЯЁ 33,
пробелы 1, пунктуация ASCII 32, прочий Unicode 100), серии «aaaa» сворачиваются,
язык = 0,4 если ≥ ¾ символов — буквы/пробелы и ≥ 3 разных букв.

**Потолок:** `min(биты H, биты G)` — djb2 32, md5 128, sha256 256; lcg 64, sfc32 128.

**Время перебора:** `2^(биты − 1) / 10¹²` попыток в секунду (средний случай).

**Уровни** (`STRENGTH_LEVELS` в `app.js`):

| Биты | Подпись |
|---|---|
| < 40 | Слабая — подбирается за секунды |
| 40–63 | Низкая — по силам обычному компьютеру |
| 64–79 | Средняя — нужны большие дата-центры для перебора |
| 80–127 | Высокая — перебор возможен вычислительными силами всей планеты |
| ≥ 128 | Максимальная — перебор невозможен в обозримом будущем |

## Как воспроизвести результат

1. В логе наведи на строку: подсказка `вход: <G> ← <H>(<отпечаток>:<соль>)`.
   В строке лога — `<H>/<G>`, источник (`✎` рисунок, `⌨` текст, или «ручной») и биты.
2. Выбери те же H и G в таблице SEED / HASH.
3. Сними галочки синхронизации у отпечатка и соли, впиши значения из подсказки.
4. Выставь тот же тип и параметры (`a`/`b`, длину, алфавит) — они в подсказку лога
   **не** записываются, их нужно помнить.
5. «Сгенерировать» → то же значение.
