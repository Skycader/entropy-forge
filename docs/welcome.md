# ENTROPY_FORGE — welcome

> **Читать первым.** Для нейросети или человека, который потерял историю чата:
> здесь всё, чтобы понять проект и продолжить работу, ничего не переспрашивая.

## Что это за проект (60 секунд)

- **Назначение.** Учебная браузерная игрушка: случайные числа и строки «из руки».
  Пользователь рисует или печатает текст → источник хешируется (DJB2 / MD5 / SHA-256,
  на выбор) → смешивается с солью → становится seed'ом генератора (LCG / SFC32, на выбор)
  → `randInt`, `double`, `randomString`. Каждый шаг виден в интерфейсе и воспроизводим.
  Не криптографический модуль — так и написано в интерфейсе.
- **Автор / роль.** Владелец — Skycader (GitHub `Skycader/entropy-forge`). Код в этой
  истории писал Claude по задачам владельца; владелец ставит задачи и принимает результат.
- **Стек.** Чистые HTML + CSS + JavaScript. Без сборки, без npm, без фреймворков,
  без внешних запросов (шрифт лежит в репозитории). Работает по `file://` и `http://`.
- **Язык.** Интерфейс и документация — русский. Комментарии в коде и сообщения коммитов —
  английский.
- **Данные.** Не хранятся нигде: ни сервера, ни `localStorage`. Рисунок, текст и лог живут
  в памяти страницы до перезагрузки.
- **Код.** [`index.html`](../index.html) (разметка) + [`css/styles.css`](../css/styles.css)
  + 6 файлов в [`js/`](../js/). Подробно — [architecture.md](architecture.md).

## Быстрый старт

| Что | Как |
|---|---|
| Открыть | двойной клик по `index.html` (работает по `file://`) |
| Локальный сервер | `python -m http.server 8765 --bind 127.0.0.1` → http://127.0.0.1:8765 (то же в [`.claude/launch.json`](../.claude/launch.json), имя `static`) |
| Сборка | не нужна |
| Тесты | автотестов нет; проверка — вручную в браузере, см. [workflow.md](workflow.md#проверка-изменений) |
| После правки JS/CSS при работе через сервер | жёсткая перезагрузка (Ctrl+F5) — браузер кеширует старые файлы |

## Правила работы

Взяты из практики проекта (истории задач и правок), а не из отдельного файла правил.

1. **Не коммитить и не пушить без просьбы.** Команда владельца **«cap»** = закоммитить
   всё и запушить в `origin/main`. Просто «коммить» = только коммит.
2. **Делать ровно то, что попросили.** Не удалять и не заменять существующие механизмы
   по своей инициативе (был случай: при добавлении выбора хеша самовольно убрал SFC32 —
   владелец попросил вернуть). Свои идеи — предлагать, а не внедрять.
3. **Перед крупной или неоднозначной задачей — уточнить.** Коротко пересказать понимание
   и задать 2–3 вопроса с вариантами и рекомендацией. Владелец часто сам заканчивает
   задачу словами «Вопросы?» / «Понятна задача?».
4. **Страница должна помещаться в экран без прокрутки** — базовое требование. Любую правку
   вёрстки проверять на наборе размеров (см. [workflow.md](workflow.md#проверка-изменений)).
5. **Каждую правку проверять в браузере**, не только в коде: клики, ввод, результат.
   Криптографию — сверять с независимой реализацией (`crypto` в Node).
6. **Работа по `file://` обязательна:** никаких ES-модулей, сборщиков, CDN и внешних
   шрифтов. Скрипты — обычные `<script defer>` с общим пространством имён `window.EF`.
7. **Интерфейс понятен без чтения.** Подсказки показывать действием (анимированный
   «призрак»), иконками и всплывашками, а не абзацами текста. Тон подписей — спокойный:
   без клоунады («кофе-брейк») и без канцелярита («NIST»).
8. **Утверждения в интерфейсе должны быть правдой.** Числа и сравнения («дольше жизни
   Вселенной», потолки энтропии) — проверять порядком величин.
9. **Обратная связь владельца:** короткие сообщения по-русски, часто скриншот с красными
   рамками. Сообщение посреди работы — поправка к текущей задаче, учитывать сразу.
10. **Крупные планы** — в [`Plan.md`](../Plan.md); реализацию начинать только по просьбе.
11. **Remote:** один, `origin` → `https://github.com/Skycader/entropy-forge.git`, ветка `main`.
    Формат коммитов — [workflow.md](workflow.md#git).
