# Рабочий процесс

[← welcome](welcome.md)

## Запуск

- **Без сервера:** открыть `index.html` в браузере (`file://`). Всё должно работать и так.
- **С сервером:** из корня репозитория
  ```bash
  python -m http.server 8765 --bind 127.0.0.1
  ```
  → http://127.0.0.1:8765. В Claude Code тот же сервер описан в
  [`.claude/launch.json`](../.claude/launch.json) (конфигурация `static`).
- **После правки JS/CSS** при работе через сервер — Ctrl+F5: браузер кеширует файлы.

Сборки, `package.json`, зависимостей и автотестов нет.

## Проверка изменений

Автотестов нет, проверка ручная — в браузере.

1. **Поведение:** прокликать изменённое (вкладки, генерацию, галочки, ползунки), посмотреть
   консоль на ошибки.
2. **Вёрстка без прокрутки** — базовое требование. Размеры, на которых проверялось:

   | Класс | Размеры |
   |---|---|
   | десктоп | 1920×1080, 1440×800, 1366×768, 1280×720, 1024×600 |
   | планшет | 768×1024 |
   | телефон, портрет | 390×844, 375×667 |
   | телефон, ландшафт | 844×390, 740×360, 667×375 |

   Проверять: `document.documentElement.scrollHeight === innerHeight` (страница) и
   `.right-col`: `scrollHeight − clientHeight === 0` (правая колонка). Для `randomString`
   проверять отдельно — его строка выше.
3. **Криптография и генераторы:** сверять с независимой реализацией, например
   `require('crypto').createHash('sha256')` в Node, и прогонять наш JS через Node
   (`global.window = {}; require('./js/hash.js')` — модули пишут в `window.EF`).

## Git

| Что | Как |
|---|---|
| Ветка | только `main` |
| Remote | `origin` → `https://github.com/Skycader/entropy-forge.git` |
| Когда коммитить | только по просьбе владельца |
| «cap» | закоммитить всё, запушить во все remote'ы, затем напомнить владельцу запустить `bash scripts/backup_to_obsidian.sh` |
| Бэкап | [`scripts/backup_to_obsidian.sh`](../scripts/backup_to_obsidian.sh): zip ровно коммита HEAD в Obsidian-хранилище (`--dest` — другая папка). Запускает только владелец; Claude — только `bash -n` |
| `.sh` в git | [`.gitattributes`](../.gitattributes): `*.sh text eol=lf`, иначе на Windows bash падает на `\r` |
| Сообщение | английский: короткий заголовок + маркированный список изменений в теле |
| Трейлер | `Co-Authored-By: Claude …` в конце (так оформлены все коммиты) |
| Переводы строк | `core.autocrlf=true`; предупреждения «LF will be replaced by CRLF» — норма |

Шрифты (`*.woff2`) — бинарные, в репозитории намеренно (работа офлайн).

## Стиль кода

- JS: IIFE с пространством имён `window.EF`, `"use strict"`, `const`/`let`, отступ 2 пробела,
  точки с запятой ставятся. Комментарии на английском, объясняют «почему».
- Тексты интерфейса — русский. Тексты всплывашек живут в `app.js` (`data-tip`, `data-tip-html`).
- CSS: цвета только через токены `:root` (`--cyan`, `--magenta`, `--amber`, `--fg-*`, `--bg-*`);
  шрифт везде `'JetBrains Mono'`; адаптивные правки — в блоках `@media` в конце файла.
- Новые зависимости, CDN, сборщики и ES-модули не добавлять — сломают `file://`.

## Планирование

Крупные задачи — сначала в [`Plan.md`](../Plan.md) или вопросами владельцу (2–3 вопроса с
вариантами и рекомендацией), реализация — после подтверждения.

## Если история чата потеряна

1. Прочитать [welcome.md](welcome.md) (правила) и этот файл.
2. `git log --stat -10` — что менялось последним; `git status` — нет ли незакоммиченного.
3. [`Plan.md`](../Plan.md) — что запланировано.
4. Запустить сервер, открыть страницу, убедиться, что консоль чистая.
5. Не коммитить, пока владелец не попросит («cap»).
