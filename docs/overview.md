## Что это и для кого

Учебная игрушка, показывающая путь от «хаоса руки» к случайному числу. Для тех, кто хочет
наглядно понять энтропию, хеш-функции, соль, seed и генераторы псевдослучайных чисел.
Каждое промежуточное значение видно и копируется, результат воспроизводим.

Внутри приложения прямо сказано: это не криптографический модуль, результат нельзя
использовать для настоящих ключей и паролей.

## Что умеет

| Область | Возможности |
|---|---|
| Источник энтропии | вкладка **рисунок** (холст, мышь/палец) или **текст** (редактор с номерами строк); содержимое вкладок хранится независимо |
| Оценка | энтропия в битах, время перебора, уровень стойкости (5 уровней), потолок по самому узкому звену |
| Хеш (отпечаток) | DJB2 / MD5 / SHA-256 — радиокнопкой в таблице SEED / HASH; невыбранные строки показывают превью |
| Соль | unix timestamp в мс с шагом 1 мс…1 мин (ползунок внутри поля) или любая строка вручную |
| Генератор | LCG (64 бит, константы Кнута) / SFC32 — радиокнопкой в той же таблице |
| Выход | `randInt(a,b)` (любые безопасные целые), `double [0,1)`, `randomString` (длина 1–512, алфавит из галочек A-Z / a-z / 0-9 / `#`) |
| Прозрачность | поля отпечатка и соли редактируются вручную; лог с подсказкой «вход», по которой значение можно повторить |
| Подсказки | всплывашки с пояснениями; у LCG — формула, у DJB2 — исходный код |
| Вёрстка | помещается в один экран без прокрутки на десктопе, телефоне в портрете и ландшафте |
| Офлайн | всё локально: шрифт и фавиконка в репозитории/HTML, внешних запросов нет |

Подробности алгоритмов — [crypto.md](crypto.md).

## Чего нет

- RSA-ключей, шифрования, подписей — запланировано в [`Plan.md`](../Plan.md).
- Сохранения между сессиями (лог, рисунок, текст пропадают при перезагрузке).
- Светлой темы (оформление намеренно только тёмное, `color-scheme: dark`).
- Криптостойкости: LCG и SFC32 предсказуемы, оценки энтропии — эвристики.
- Автотестов, сборки, пакетного менеджера.
