## Старт приложения

[`index.html`](../index.html) подключает стили и шесть скриптов обычными `<script defer>`
(не ES-модули — чтобы работало по `file://`). Порядок важен:

| # | Файл | Экспортирует в `window.EF` | Зависит от |
|---|---|---|---|
| 1 | [`js/entropy.js`](../js/entropy.js) | `EF.entropy` | — |
| 2 | [`js/hash.js`](../js/hash.js) | `EF.hash` | — |
| 3 | [`js/prng.js`](../js/prng.js) | `EF.prng` | — |
| 4 | [`js/pad.js`](../js/pad.js) | `EF.createPad` | — |
| 5 | [`js/app.js`](../js/app.js) | — (всё связывает) | 1–4 |
| 6 | [`js/tooltip.js`](../js/tooltip.js) | — (сам вешает обработчики на `document`) | — |

Каждый файл — IIFE вида `(function (EF) { … })(window.EF = window.EF || {});`.
`app.js` при загрузке сразу инициализирует интерфейс (в конце файла: `updateAlgLabels()`,
`updateStats()`, `startTicker()` и т.д.).

## Карта файлов

| Путь | ~строк | Роль |
|---|---|---|
| `index.html` | ~290 | вся разметка; фавиконка (кубик) встроена data-URI; блок «как это работает» |

| `js/app.js` | ~680 | состояние и UI: вкладки, отпечаток, соль, таблица хешей, статистика, генерация, лог |
| `js/tooltip.js` | ~60 | одна всплывашка на `<body>` для `[data-tip]` / `[data-tip-html]` |

| `Plan.md` | — | дорожная карта |
| `.claude/launch.json` | — | конфиг локального сервера для Claude Code (`python -m http.server 8765`) |

## Основной поток данных

```
рисунок (pad.js) ─┐                                  выбор H: djb2 | md5 | sha256
текст (textarea) ─┴─▶ активный источник ──▶ отпечаток = H(источник) ──▶ поле fpInput
                         │                                   (синхронизация галочкой fpSync)
                         ▼
                  оценка энтропии ──▶ шкала стойкости
                  (entropy.js, потолок = min(биты H, биты G))

fpInput + ":" + saltInput ──▶ mix = H(…) ──▶ seed = первые N байт ──▶ G(seed) ──▶ randInt / double / string
          (соль: тикер Date.now() или вручную)            N: lcg 8, sfc32 16      выбор G: lcg | sfc32
```

Точные форматы и формулы — [crypto.md](crypto.md).

Ключевые функции `app.js`:

| Функция | Когда вызывается | Что делает |
|---|---|---|
| `onSourceChanged(immediate)` | изменился рисунок/текст, смена вкладки или хеша | счётчик, статистика, пересчёт отпечатка (с задержкой 60 мс, либо сразу) |
| `refreshFingerprint()` | после изменения источника | считает отпечатки **всех трёх** хешей (для превью), пишет выбранный в поле, если включена синхронизация |
| `onSeedInputsChanged()` | изменились отпечаток, соль, хеш или генератор; каждый тик соли | обновляет таблицу SEED / HASH и состояние кнопки |
| `updateStats()` | изменился источник / хеш / генератор | биты, время перебора, шкала и подпись уровня |
| обработчик `genBtn` | клик или Enter в поле генератора | новый генератор из текущих полей, результат, запись в лог |

## Вёрстка

- Страница ровно в высоту экрана (`.app` с `min-height: 100dvh`), холст — наибольший
  квадрат, который помещается (container query units `cqw`/`cqh`).
- Левая колонка: холст / текст + метрики. Правая: генератор, таблица SEED / HASH, лог,
  «как это работает».
- Режимы (`@media` в конце `styles.css`):
  - низкие окна (`max-height` 820 / 760 / 680) — прячутся второстепенные тексты, строки плотнее;
  - телефон в портрете (`max-width: 879px` + portrait, или `max-width: 639px`) — одна колонка,
    нижние панели свёрнуты в ряд кнопок, галочки алфавита 2×2;
  - низкий ландшафт (`max-height: 500px` + landscape) — метрики справа от холста, кнопка
    генерации только `▶`.
- Поле текста: высота округляется вниз до целого числа строк (CSS `round()`), чтобы не было
  обрезанной строки.

## Подводные камни

- **Медиа-запрос компактного режима продублирован**: строка в `app.js` (`const compact = matchMedia(…)`)
  должна совпадать с запросом в `styles.css`. Меняешь один — меняй второй.
- **«Магические» пиксели в CSS**: ширина левой колонки `calc(100dvh - 270px)`, ширина холста в
  ландшафте `calc(100vw - 456px)` / `calc(100dvh - 76px)` подобраны под текущие отступы.
  Поменял отступы панелей — перепроверь, что всё влезает.
- **Высота правой колонки впритык**: таблица SEED / HASH (5 строк), лог и генератор едва
  помещаются на 1280×720. Добавил строку — проверь прокрутку правой колонки (`.right-col`).
  Рычаги: `min-height` у `.log-panel` и плотность `.hash-row` в `@media (max-height: 760px)`.
- **Кеш браузера** при работе через `http.server`: после правки JS браузер может держать старую
  версию файла (было: «`makeCounterRng` is not a function» из старого `prng.js`). Ctrl+F5.
- **`data-tip-html` вставляется через `innerHTML`** — задавать его только из своего кода, никогда из ввода пользователя.
- **Устаревшие комментарии в шапках файлов** (не проверены как ошибки, просто неточность):
  шапка `app.js` пишет «hash H (md5 | sha256)», хотя есть ещё DJB2; шапка `entropy.js` —
  что потолок по размеру хеша, а фактически `min(хеш, генератор)`.
- **Анимации «призраков»**: рисунок — SMIL внутри SVG (`#ghost`, управляется
  `pauseAnimations` / `setCurrentTime`), текст — таймеры в `app.js`. Оба учитывают
  `prefers-reduced-motion`. В фоновой вкладке браузера таймеры притормаживаются — это норма.
- **Точки рисунка хранятся в координатах холста на момент начала пула** (`refWidth` в `pad.js`)
  и масштабируются при отрисовке — поэтому изменение размера окна не меняет хеш.
